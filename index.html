Face Puppet · 2.5D portrait animator

Upload a portrait, press Start Camera, and your head pose, blinks, gaze, jaw and expressions drive the photo in real time. This is layered 2.5D animation — not true 3D reconstruction: unseen sides of the head, hidden teeth and closed-eye interiors are approximated, never recovered.

Permission: please animate only photos you own or have permission to use. All processing happens locally in this browser — photos and webcam frames are never uploaded anywhere.

Genuine limitations (please read)
2.5D onlyHead turns are limited to about ±25° yaw, ±15° pitch, ±20° roll. This is not a 360° model. EyesIf the source photo has closed or occluded eyes, opening them cannot be reconstructed — blinks and gaze stay subtle. TeethVisible teeth are procedural; they suggest, not reproduce, the real dentition. Far sideTurns reveal stretched edge pixels, not unseen anatomy. Hair, ears and background stay mostly static by design. TrackingNeeds decent lighting and a roughly front-facing performer. Fast motion may lag; smoothing trades latency for stability.
How to run

Serve this single file over HTTP(S) — e.g. python3 -m http.server 8000 then open http://localhost:8000/index.html — or open it from any static host with HTTPS. No build step, no backend, no API key. The page loads pinned Three.js, MediaPipe Tasks Vision and the face model from CDNs, so first load needs internet. Chrome or Edge on a laptop is recommended.
